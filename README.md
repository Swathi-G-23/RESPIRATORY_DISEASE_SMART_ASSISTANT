# 🫁 Respiratory Disease Smart Assistant

An AI-powered healthcare application that predicts respiratory diseases using patient symptom analysis and video-based respiratory pattern detection.

## ✨ Key Features

* **Symptom-Based Disease Prediction:** Predicts potential respiratory diseases based on patient clinical indicators and symptom severity.
* **Video-Based Respiratory Pattern Detection:** Utilizes a custom YOLOv8 model for real-time visual respiratory pattern analysis.
* **Interactive Streamlit Interface:** Modern, user-friendly, and responsive dashboard.
* **Confidence & Metrics:** Real-time prediction outputs with confidence scores.
* **Medical Report Generation:** Generates downloadable summary reports in PDF format.

## 💻 Local Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Swathi-G-23/RESPIRATORY_DISEASE_SMART_ASSISTANT.git
   cd RESPIRATORY_DISEASE_SMART_ASSISTANT
   ```

2. **Create and activate a virtual environment (optional):**
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # macOS/Linux:
   source venv/bin/activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Launch the application:**
   ```bash
   streamlit run app.py
   ```
